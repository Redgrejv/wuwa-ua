# wuwa-ua

Український переклад діалогів **Wuthering Waves** у реальному часі: захоплення екрана → OCR →
переклад → плашка поверх англійського субтитра.

Гру не модифікує й у її файли не лізе — читає лише зображення з екрана.

| | |
|---|---|
| Затримка на нову репліку | ~250 мс на GPU, ~800 мс на CPU |
| Переклад | NLLB-200-distilled-1.3B через CTranslate2, локально |
| OCR | tesseract, два препроцесори паралельно, вибір за впевненістю |
| VRAM | ~2.1 ГБ на GPU, або нуль у режимі CPU |

## Що воно вміє

- **Плашка поверх оригіналу** з розмитим фоном і обводкою на кожній літері.
- **Рід мовця**: розпізнає ім'я над реплікою й перегинає дієслова минулого часу, тож жіночі
  персонажі не говорять про себе в чоловічому роді.
- **Глосарій** власних назв — підставляються дослівно, без спотворення.
- **Кеш**: повторна репліка не перекладається вдруге.
- **Вікно історії** з усім діалогом, оновлюється саме.
- **Гарячі клавіші в грі**: `Page Up` — сховати/показати, `Page Down` — перекласти наново,
  `Home` — відкрити історію. Поза грою ці клавіші працюють як завжди, а перепризначити їх можна
  у вікні `wuwa-ua settings`.
- **Автозапуск разом із грою.**

## Встановлення: Windows

> Перевірено не було — код для Windows написано, але на живій системі не запускався.
> Якщо щось не працює, це очікувано; пиши, полагоджу.

Одна команда в PowerShell:

```powershell
irm https://raw.githubusercontent.com/Redgrejv/wuwa-ua/master/scripts/bootstrap.ps1 | iex
```

Скрипт склонує проєкт у `%LOCALAPPDATA%\Programs\wuwa-ua` і встановить усе потрібне. Повторний
запуск тієї ж команди оновлює наявну копію.

Він зробить усе сам: перевірить Python 3.12+, поставить Tesseract через `winget`, створить
віртуальне середовище, підтягне залежності, завантажить модель перекладу (~1.4 ГБ), скопіює
типовий конфіг і створить `wuwa-ua.cmd`.

Якщо є відеокарта NVIDIA, він додатково поставить CUDA-бібліотеки — переклад буде приблизно
вп'ятеро швидшим.

**Гру треба запускати у режимі «вікно без рамки» (borderless)**, інакше плашка не ляже поверх.

Далі:

```powershell
.\wuwa-ua.cmd calibrate --monitor screen   # виділити зону субтитрів мишею
.\wuwa-ua.cmd run                          # запустити переклад
```

## Встановлення: Linux

Потрібні: Wayland із порталом захоплення екрана (перевірено на KDE Plasma 6), Python 3.12+,
`tesseract`, GTK 4 і `gtk4-layer-shell` для оверлея.

```bash
# Arch / Manjaro
sudo pacman -S tesseract tesseract-data-eng gtk4 gtk4-layer-shell python-gobject python-cairo

git clone https://github.com/Redgrejv/wuwa-ua.git
cd wuwa-ua
python -m venv --system-site-packages .venv
.venv/bin/pip install -e ".[dev]"
.venv/bin/pip install python-xlib huggingface_hub

# модель перекладу
.venv/bin/python -c "from huggingface_hub import snapshot_download; \
  snapshot_download('JustFrederik/nllb-200-distilled-1.3B-ct2-int8', \
  local_dir='$HOME/.local/share/wuwa-ua/models/nllb-1.3b')"

# конфіг
mkdir -p ~/.config/wuwa-ua
cp config/config.linux.toml ~/.config/wuwa-ua/config.toml
cp config/glossary.tsv config/speakers.tsv ~/.config/wuwa-ua/
```

Для GPU (необов'язково, але вп'ятеро швидше):

```bash
.venv/bin/pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
```

Зручний запуск одним словом:

```bash
printf '#!/usr/bin/env bash\nexec %s/.venv/bin/python -m wuwa_ua.cli "$@"\n' "$PWD" > ~/.local/bin/wuwa-ua
chmod +x ~/.local/bin/wuwa-ua
```

## Користування

```bash
wuwa-ua run        # запустити переклад (гра має бути вже запущена)
wuwa-ua watch      # чекати на гру й піднімати переклад разом із нею
wuwa-ua history    # окреме вікно з усім діалогом
wuwa-ua toggle     # сховати / показати
wuwa-ua refresh    # перекласти поточну репліку наново
wuwa-ua status     # running або paused
wuwa-ua settings   # вікно налаштування гарячих клавіш
wuwa-ua calibrate --monitor DP-4   # перевиділити зону субтитрів
```

У грі те саме роблять `Page Up`, `Page Down` і `Home`.

При першому запуску на Linux система запитає дозвіл на захоплення — вибери **вікно гри**,
а не монітор. Це важливо: при захопленні монітора наша ж плашка потрапляє у власний потік,
і система починає перекладати свій переклад. На Windows цієї проблеми немає — вікно оверлея
позначене як виключене із захоплення.

## Налаштування

Конфіг: `~/.config/wuwa-ua/config.toml` (Linux) або `%APPDATA%\wuwa-ua\config.toml` (Windows).

| Ключ | Що робить |
|---|---|
| `[region]` | зона субтитрів у частках екрана; заповнюється командою `calibrate` |
| `[display] plate_top` | верх плашки — рівень розділювача під іменем мовця |
| `[display] clear_after` | через скільки секунд тиші прибирати плашку |
| `[translate] device` | `cuda` або `cpu` |
| `[translate] beam_size` | ширина променя; менше — швидше, більше — трохи якісніше |
| `[hotkey]` | клавіші та вікно, у якому вони перехоплюються |

**Глосарій** (`glossary.tsv`) — власні назви, рядок `англійська<TAB>українська`. Термін
підставляється у джерело до перекладу й доходить до результату дослівно.

**Статі мовців** (`speakers.tsv`) — рядок `Ім'я<TAB>f` або `m`. Якщо персонажа немає в таблиці,
рід не виправляється. Ім'я з гри розпізнається неточно, тому пошук працює з допуском.

У таблиці зібрані всі резонатори. **NPC там немає**, і зібрати їх наперед не вийде: вікі гри поля
статі для NPC просто не веде. Тому кожен нерозпізнаний мовець дописується у
`speakers-unknown.tsv` рядком `ім'я<TAB>?` — лишається змінити `?` на `f` чи `m` і перенести
рядок у `speakers.tsv`. Так таблиця наповнюється тими, кого ти справді зустрічаєш, а не
вісьмома сотнями імен, більшість яких у діалогах не з'явиться.

## Обмеження

- Рід виправляється лише в **дієсловах минулого часу**; прикметники (`я була одержим*им*`)
  лишаються в чоловічому роді.
- Модель зрідка плутає відмінки. Перевірено, що більша модель (NLLB-3.3B) цього **не виправляє**
  й додатково втрачає частини речень, тож нарощувати розмір сенсу немає.
- OCR іноді читає `I` як `|` та плутає літери у стилізованих іменах — частину таких помилок
  прибирає нормалізація й нечіткий пошук, але не всі.
- Варіанти відповіді в діалозі поки не перекладаються.

## Розробка

```bash
.venv/bin/python -m pytest -q
```

Тестів 276. Платформо-залежні частини (захоплення, оверлей, хоткеї) покриті лише в чистих
частинах — геометрія, розбір, вибір пристрою; самі виклики до системних API перевіряються руками.

Архітектура й журнал рішень — у `docs/superpowers/plans/2026-09-05-wuwa-ua.md`. Там же записано,
які припущення реальні дані спростували: це найкорисніша частина, якщо доведеться щось міняти.
