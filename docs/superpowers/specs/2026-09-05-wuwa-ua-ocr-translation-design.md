# wuwa-ua — переклад діалогів Wuthering Waves на українську

Дата: 2026-09-05

## Задача

Wuthering Waves не має української локалізації і не матиме її найближчим часом. Мета — читати
англійські діалогові субтитри просто з екрана й показувати український переклад у реальному часі,
не торкаючись гри.

## Обмеження, з яких випливає рішення

Розвідка встановленого клієнта (`~/Games/steamapps/common/Wuthering Waves`) показала:

- Pak-файли мають версію **12** — кастомний формат Kuro, ванільні `repak`/`u4pak` їх не читають.
- Індекс кожного пака **зашифровано AES** (`encrypted_index=1`), стиснення — Oodle.
- Біля кожного пака лежить `.sig` — файл підпису цілісності.
- Офіційні мови в маніфестах: `zh`, `en`, `ja`, `ko`. Мов на кирилиці немає взагалі.
- У `ResManifest` за два тижні (20.08 — 01.09.2026) вісім версій ресурсів: 3.6.6 → 3.6.13.
- Клієнт — чистий Steam-білд із kernel-level античитом ACE.

Тому обидва варіанти з модифікацією клієнта відкинуто:

**Патч мовного пака** вимагає обходу шифрування контенту гри, ламається об `.sig` і ACE, потребує
підміни шрифтів (кирилиці в офіційних мовах немає) і розвалювався б при кожному з восьми патчів
за два тижні.

**Інжект у процес гри** знімає проблему шифрування (текст читається вже розшифрованим у пам'яті),
але детектується античитом надійніше за підміну файлів, а не слабше, і вимагає дампу SDK під
кастомний UE-білд.

**Обраний підхід — OCR з екрана.** Єдиний, що не має жодного контакту з процесом і файлами гри:
читає фреймбуфер, як це робить OBS. Переживає будь-який патч гри.

## Середовище

- Manjaro Linux, KDE Plasma на Wayland, `xdg-desktop-portal-kde` 6.7.4, PipeWire 1.6.8.
- Чотири монітори: три 2560x1440 (DP-3, DP-4, DP-5) і один 1920x1080 (HDMI-A-3).
- NVIDIA RTX 4070 Ti, 12 ГБ VRAM, з яких ~3 ГБ зайнято десктопом у простої.
- Гра запускається під Proton зі Steam.

Треба доставити: `tesseract-data-eng`, `python-opencv`, `ollama`.
Вже є: `tesseract` (тільки дані `afr`/`osd`), `python3`, `python-gobject`.

## Архітектура

Демон на Python. Конвеєр:

```
portal/PipeWire стрім монітора гри
   → кроп зони субтитрів
   → детектор змін + гейт стабілізації
   → OCR (eng)
   → нормалізація тексту
   → кеш SQLite ──хіт──→ вивід
        │ міс
        └→ ollama (глосарій + контекст) → кеш → вивід
```

### Модулі

Кожен модуль має одну відповідальність і тестується окремо.

| Модуль | Відповідальність | Залежить від |
|---|---|---|
| `config` | читання TOML, валідація, дефолти | — |
| `capture` | постійний ScreenCast-стрім, видача кадрів | portal, PipeWire |
| `region` | зони екрана в нормалізованих координатах, калібрування | `config` |
| `detect` | виявлення зміни кадру + гейт стабілізації | — |
| `ocr` | розпізнавання тексту з кропу | бекенд |
| `normalize` | чистка OCR-виводу, склейка рядків | — |
| `translate.cache` | SQLite-кеш перекладів | — |
| `translate.glossary` | глосарій власних назв, збірка промпту | `config` |
| `translate.ollama` | виклик локальної моделі | ollama HTTP |
| `display` | показ репліки | бекенд |
| `pipeline` | склеювання всього, черга задач | всі вище |
| `cli` | команди, керування демоном | `pipeline` |

### Ключові інтерфейси

```python
class CaptureSource(Protocol):
    def frames(self) -> Iterator[Frame]: ...

class OcrBackend(Protocol):
    def recognize(self, image: Image) -> OcrResult: ...   # text, confidence

class Translator(Protocol):
    def translate(self, text: str, context: Sequence[str]) -> str: ...

class Display(Protocol):
    def show(self, line: SubtitleLine) -> None: ...
    def clear(self) -> None: ...
```

Два бекенди OCR (`tesseract`, `vlm`) і два бекенди виводу (`window`, `overlay`) реалізують
відповідний протокол. Заміна бекенда не зачіпає решту конвеєра.

### Захоплення екрана

Один постійний ScreenCast-стрім через `xdg-desktop-portal-kde` з **restore-токеном**, збереженим
у конфізі — дозвіл питається один раз, а не щозапуску. Кадри читаються через `pipewiresrc`
(GStreamer, `python-gobject` уже встановлено).

Частота семплювання — 4 кадри/с. Повний кадр не обробляється: одразу береться кроп зони субтитрів.

### Детектор змін і гейт стабілізації

Кроп ужимається до ширини 64px у відтінках сірого й порівнюється з попереднім за середньою
абсолютною різницею.

Критично: OCR запускається **не** одразу після зміни, а коли кадр змінився й потім **застиг** на 2
послідовних семпли (~500 мс). Субтитри в грі анімуються посимвольно, тож без цього гейта
розпізнавалися б обірвані півфрази.

Пороги (конфігуровані): поріг зміни — середня різниця > 3.0; стабільність — 2 кадри.

### OCR

Tesseract із даними `eng`. Препроцесинг під світлий текст на темній напівпрозорій плашці:
масштабування 2x, відтінки сірого, інверсія, поріг Отсу. Рядки з упевненістю нижче 60 відкидаються.

Головний технічний ризик проєкту — стилізований шрифт гри. Саме тому OCR схований за інтерфейсом:
якщо харнес точності покаже незадовільний результат, вмикається бекенд `vlm` (локальна візуальна
модель через ollama) без переробки конвеєра.

### Переклад

ollama, компактна instruct-модель. У промпт іде:

- системна інструкція: переклад EN→UK, ігровий діалог, зберігати тон і регістр, віддавати **тільки**
  переклад без пояснень;
- глосарій власних назв, звужений до тих, що зустрілися в поточному рядку;
- останні 3 репліки як контекст сцени.

**Глосарій** — редагований користувачем TSV `англійська<TAB>українська` (Rover, Scar, Jinhsi,
Huanglong тощо). Потрібен, щоб імена не плавали від репліки до репліки. Стартує майже порожнім і
наповнюється в процесі.

**Кеш** — SQLite `нормалізований оригінал → переклад`. Повторні репліки віддаються миттєво;
з часом це стає пам'яттю перекладів, яку можна правити вручну.

### Вибір моделі

Розмір моделі не фіксується в специфікації, бо залежить від виміру. Окремий крок плану: заміряти
вільну VRAM **під час реальної гри** (12 ГБ мінус ~3 ГБ десктопу мінус те, що займе гра), і за
цією цифрою обрати модель. Якщо жодна прийнятна не влазить у VRAM — переклад іде на CPU; репліки
короткі, затримка терпима.

### Вивід

Два режими, перемикаються на льоту:

- **`window`** — вікно, закріплене на обраному моніторі: поточна репліка великим шрифтом плюс
  історія попередніх. Гра при цьому спокійно йде фулскріном на своєму екрані.
- **`overlay`** — прозора click-through layer-surface (`gtk4-layer-shell`) над зоною субтитрів гри.

### Керування демоном

На Wayland застосунок не може перехоплювати глобальні клавіші самотужки. Тому демон слухає unix-сокет
і приймає команди (`toggle`, `mode window|overlay`, `pause`, `resume`), а CLI надсилає їх у сокет.
Гарячі клавіші вішаються штатними засобами KDE (Custom Shortcuts) на виклик CLI — це працює й
поверх фулскріну гри, і не потребує жодних привілеїв.

## Обробка збоїв

Принцип: конвеєр ніколи не блокується й ніколи не мовчить.

| Ситуація | Поведінка |
|---|---|
| ollama недоступна або думає > 4 с | показати англійський оригінал із позначкою, конвеєр працює далі |
| прийшла нова репліка, поки старий переклад у роботі | старий результат відкинути, не показувати |
| стрім обірвався (alt-tab, зміна конфігурації моніторів) | реконект із експоненційним бекофом |
| OCR дав порожнечу або сміття (упевненість < 60) | пропустити, **не** стирати попередній рядок |
| зона субтитрів не відкалібрована | відмовитись стартувати з підказкою запустити калібрування |

Переклад виконується в окремому воркері; черга захоплення ніколи його не чекає.

## Тестування

Юніт-тести на чистих модулях:

- `detect` — на синтетичних послідовностях кадрів: зміна є / зміни немає / зміна без стабілізації;
- `normalize` — чистка типових артефактів OCR;
- `translate.glossary` — збірка промпту, звуження глосарію під рядок;
- `translate.cache` — запис, читання, нормалізація ключа;
- `config` — валідація, дефолти, помилки.

**Харнес точності OCR**: набір реальних скріншотів субтитрів гри з еталонним текстом, рахує
відсоток помилок посимвольно. Саме він дає відповідь, чи вистачає tesseract, чи потрібен VLM.

Тести перекладу — на замоканій ollama (перевіряється сформований промпт, не якість моделі).
Якість перекладу й загальна робота конвеєра перевіряються вручну в грі.

## Розташування файлів

```
~/.config/wuwa-ua/config.toml        конфіг: зони, пороги, модель, режим виводу, restore-токен
~/.config/wuwa-ua/glossary.tsv       глосарій власних назв
~/.local/share/wuwa-ua/cache.sqlite  кеш перекладів
~/.local/share/wuwa-ua/history.jsonl лог реплік
$XDG_RUNTIME_DIR/wuwa-ua.sock        сокет керування демоном
```

## Межі v1

**Входить:** діалогові субтитри, автоматичний режим із детектором змін, два режими виводу,
глосарій, кеш, калібрування зони.

**Не входить:** переклад меню, описів предметів і квестів; озвучка; автопошук вікна гри; GUI
налаштувань (досить TOML); OCR японської та китайської.
